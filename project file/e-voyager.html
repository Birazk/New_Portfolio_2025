Features
  • ML models: Random Forest, neural network, SVR, gradient boosting, and linear regression.
  • Physics model: theoretical energy use from vehicle dynamics.
  • Economics: EV vs. petrol and diesel cost comparison for Nepal.
  • Route tools: energy-efficient path planning and geospatial maps.
  • Storage: PostgreSQL for data and trained models.
Model comparison

The project README reports Random Forest as the best performer (R² 0.87, RMSE 1.98 kWh/100 km), ahead of gradient boosting (0.85) and the neural network (0.82).
