Research at ESTRL

I developed machine learning models for battery state-of-health prognostics using real-time data from five public electric buses, with reported prediction accuracy above 95%. The models support predictive maintenance and second-life battery modeling.

Open-source tool · Battery Health Tracker

I packaged the approach into a multi-page Streamlit application for EV battery SOH prediction across cars, buses, trucks, and motorcycles.

  • Data ingestion: import and process battery data.
  • Model training: Random Forest and XGBoost with hyperparameter optimization; optional LSTM for time series.
  • Real-time prediction: live SOH estimates with confidence intervals.
  • Fleet dashboard: monitor a whole fleet's battery health.
  • Model comparison: side-by-side performance analysis.
  • Storage: PostgreSQL database and Plotly visualizations.
